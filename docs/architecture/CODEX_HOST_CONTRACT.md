# Codex 首发适配合同

**性质：本轮工程裁定，不是 Codex 当前官方接口的核验报告。** 上位逻辑为 [ARCHITECTURE](ARCHITECTURE.md)。原 F1–F3 源自结项评审；评审原件保存在整理前 Git 历史，定义依据见 [历史章节索引](../references/README.md)。

## C1｜确定宿主和可支持范围

宿主家族由用户选为 **Codex**。首个部署形态由本包确定为 **Codex CLI 的本地/CI 单任务非交互运行**，一个 run 只有一个不可变原始任务合同、一个授权域和一份受保护配置。目标为受控 Linux 运行环境；不声称覆盖 Codex Web、桌面、IDE 全部模式或其他操作系统。

选择非交互单任务，是因为外部工具仅凭调用参数不能可信观察所有聊天变化。运行器在启动前确认任务与 Hard Context；新的用户任务、修改 Required Reads、切换身份或工作区都由运行器更新 epoch/停止旧 run，不让模型在一次工具调用中自行替换授权合同。不能保证这一点的交互会话只允许原流程，不启用披露。

同一 Codex run 内可能实际共享工具通道的执行者，一律视为**同一个授权域**。不声称 stdio 能识别每个内部 subagent；不对不同权限的 agent 共用 provider。原生 subagent 能力是否启用由已核验宿主决定，但本期不筛选其报告，不提供跨身份视图共享。

**二进制版本不指定“latest”。** W1 锁定真实 `codex --version`、可执行入口 hash、分发工件标识/校验、配置 hash、MCP 协议/SDK版本和 provider build。当前无二进制，字段为 null 并阻止真机验收。Codex CLI 是选定产品形态，不等于随便一个版本都可用。

## C2｜F1 的解法：在自有工具内部完成 ADMIT

```text
Codex CLI 主循环
    ├─ 原生 search/read/edit/test → 原样，由 Codex 负责
    └─ 已配置的本地 stdio MCP provider
           ├─ srr_search：授权搜索 → 完整结果 → B/可选C → 单次工具返回
           └─ srr_recall：当前授权 → 固定旧源 → 明确范围/分页 → 单次工具返回
```

工具名由本项目定义，不是声称 Codex 内置同名工具。MCP transport 通过目标版本支持的 SDK 实现；不自行复制 agent loop 或实现通用事件总线。首发 provider 由运行器部署，实际 Codex 启动/配置语法在 W1 从该版本核对；本包不发布假安装命令。

**不依赖**全局 `PostToolUse`、日志订阅能改写结果、app-server 通知等于前置接缝等未经证实的能力。provider 在自己输出前决定返回内容，因此逻辑上不需要截获任意原生工具。Codex 是否会实际调用、如何承载返回、是否自动截断，仍需 trace 核验。

只覆盖真实经过 `srr_search` 的搜索；Codex 原生 shell/read/search 不被封锁，也不被宣称覆盖。覆盖成本以整任务计，未调用 provider 的任务仍保留在分母。安装工具本身不是成功接入证据。

### 自有搜索的最小确定义

首版只做 **literal UTF-8 text search**，不接受 shell 字符串、不执行模型提供的命令、不支持任意正则/远程 URL。`query` 为非空字面串；候选 path 只从运行器授权文件清单的子集中选择。绝对路径、`..`、符号链接逃逸、非普通文件和未授权文件拒绝。查询范围、顺序、上下文行数、忽略列表、截断/错误都随结果明确记录。

实现按固定源顺序输出连续片段并声明来源/版本；未知结构依赖不据此宣称安全。文件读取必须在实际 FD/沙箱边界上检查，而不是只做字符串过滤。并发文件改写造成无法保证捕获完整时返回 partial/unknown，不把混合视图包装成一致仓库快照。hash 绑定本次捕获，不承诺整个工作区的原子 Git 状态。

运行器声明的 Required Reads 保持完整原生可得且不筛；匹配保护路径的搜索结果全部保护。搜索摘录不是“已履行完整文件必读”的证明。模型 `full=true` 只能增加披露，不可缩小保护。

### 收件、重复和取消

provider 把一份已渲染响应交给 transport，不另外给 Codex 注入第二条消息。`RESPONSE_WRITTEN` 仅表示服务端输出动作；只有宿主可核对的实际模型请求/收件证据才能标 `DELIVERED`。

每个**实际调用实例**有唯一内部 invocation ID，绑定 run、连接 epoch 和当时的 transport request；不把模型传入 `call_id` 当身份，不跨连接复用 request ID 作全局幂等键。内容相同的合法新调用仍是新事件并计费，不按相同 query 静默折叠。重复内部回调只允许一个返回。

发送前取消丢弃候选响应；发送中断/回执不明保留 `DELIVERY_UNKNOWN`，不盲发第二份全文，不偷偷重放。运行器停止受影响调用或 run 并保留证据。目标 Codex 版本必须提供可用于 E0 核对的真实出站构造/请求证据；仅有 provider 日志、CLI 最终回答或模型复述不够。必要时在授权的本地源码构建中观测实际请求构造位置，不通过窃取凭据或绕过传输安全取证。

如果该版本没有可验证路径，则 H02/H08 不通过，保持 off；不以我们拥有工具边界为由冒充已观测模型输入。

## C3｜F2 的解法：启动器声明授权，工具参数只能收窄

信任根是操作方运行器生成的 **run manifest**，从 agent 不可写的配置位置载入。Codex session 与 provider 的通道由运行器绑定；MCP 参数、仓库文件、AGENTS.md 的自然语言、selector 标签都不能创建或升级授权。

manifest 至少含 run/任务 hash、授权 epoch、工作区及文件清单、Hard/Soft 声明、外发许可、source quota、运行/保留边界、批准的配置 hash 与 principal binding。缺失可信字段时只能维持无新延后的原流程。

| 数据流 | 本包裁定 |
|---|---|
| 读取仓库 | 独立受授权清单及实际进程隔离约束；不假定 Codex 沙箱自动覆盖外部 MCP |
| 保存源和最低日志 | 仅保存本来允许交付的表示；由运行器授权，provider 私有存储，不置于 agent 可写项目树 |
| 发送给语义后端 | 默认禁止；只有另外的明确数据许可和后端版本校验后可考虑 C |
| 向 Codex 披露/召回 | 当前授权下同一 run 的可读数据；旧 handle 不绕过撤权 |
| 给 evaluator 的输入 | 独立可访问合法任务全证据，但验收答案与标签不得出现在 Codex/provider 工作区 |

MCP transport/SDK 的安全行为、OS UID/容器挂载和网络策略须现场验证。一个本地文件 `chmod 0700` 在 agent 和 provider 同 UID 时并不能形成所需隔离；目录叫 private 也不能。优先复用运行器已有隔离，无法隔离则不开启不满足该边界的实验。

撤权/任务 epoch 变更由可信运行器触发，provider 每次执行和返回前、每次 recall 读前核对。到达进程边界的授权快照决定该操作的线性化点；撤权后新读取必须拒绝，已经交付内容不能承诺撤回。源包含多授权单元时，首版采用保守整源拒绝，不返回部分内容假装请求完整。

攻击性正文不能修改协议控制字段。固定工具描述只解释读法与限制，不反复提醒模型“你确定吗”。防正文诱导的语义风险仍需要 E3/E4，不因 JSON schema 有效而声明已解决。

## C4｜F3 的解法：单 run 事务存储与直接原文读取

首发选 **SQLite 嵌入式事务存储**，源正文、块范围、K/D、manifest hash、最小决策和引用记录同一事务提交；一 run 一数据库，非数据库集群。写入提交之前不得输出依赖它的 handle。启用 foreign keys、WAL 与 FULL 同步属于实现要求，但真实文件系统、崩溃恢复与隔离保证仍须验收，不能仅引用配置名。

handle 是随机不透明标识；hash 用于校验不用于授权。blob 保存允许交付的旧 UTF-8 表示，recall 不回读同路径的新文件、不重新筛选。源损坏/失效则明确拒绝或报错，其错误细节按宿主保密要求裁剪。

`srr_recall` 的逻辑操作固定为：

| operation | 语义 |
|---|---|
| `list_views` | 只列当前授权 run 内可发现的视图与来源状态，可分页；为丢失 handle 的同 run 恢复提供入口 |
| `list_deferred` | 枚举指定 view 原始 D 的授权目录，不表示“尚未理解” |
| `read_blocks` | 读取指定 ID 集合；不补入中间块，重复 ID 或任一无效/越权项整体拒绝 |
| `read_deferred` | 取指定 view 最初 D，和其他调用是否读过无关 |
| `read_snapshot` | 固定旧快照的完整可遍历原文，不表示已搜索整个仓库 |

所有分页游标绑定 run、授权版本、source/version、view、operation、规范化范围与偏移；每页必须取得进展。最终以源序重建，授权变化后的 cursor 不继续读取。工具请求不能用自报 recipient 获得别人的 view。

`list_views` 是对已有“延后可发现”合同的最小落实，不是跨会话记忆/全局 Registry。它只保证有合法取回入口，不保证 Codex 在 compaction 后主动调用或正确理解，后者留 E4。

### 生命周期与故障

run 状态为 `ACTIVE → DRAINING → CLOSED`，另有可信 `REVOKED`。关闭语义仅退 B；关闭 admission 停止新增 D；两者都不删除仍合法活跃源。普通配额耗尽先停新延后，不逐出旧承诺。任务最终回答不自动销毁源。

可信操作方明确关闭 run 后可按数据保留策略清理；重新开始任务不能自动复用旧授权。source quota 和允许 run 的时间/关闭合同在部署前必须填写，未填不能激活。不得为了局部节省承诺无限期无条件保留。

provider 重启同一 run 时读取原事务存储，核对同一授权 manifest，恢复目录仍可查询；schema 不兼容的版本不得对活跃 run 强行升级，使用旧读取器排空或拒绝升级。目标版本实际运行中可能发生的 compaction 不被简单排除，H12 必测。跨新任务迁移和多个身份之间自动共享不支持。

写源/最小日志失败、保护闭包超限、整体信封超限都不能输出伪 handle。完整读取需要有真实可用的分页路径；若单页表示都无法容纳最小合法信息，返回显式错误并停止该干预，不报告“已回退所以发送成功”。

## C5｜设计已定与事实未验分开

| 旧阻塞 | 本包设计处置 | 真机闭合证据 |
|---|---|---|
| F1 | Codex CLI 单任务＋自有 stdio MCP 工具返回；不做全局后置拦截；未知交付停止 | 版本/配置锁、真实下一模型请求、取消/重复/未知交付 trace |
| F2 | 可信 run manifest＋单授权域＋独立进程/挂载约束；外发默认关闭 | 实际 session 绑定、不可伪造保护、撤权、数据可见范围与网络限制 |
| F3 | SQLite 提交后发引用＋同 run 目录/分页＋活跃源保留/回滚 | 真正工具召回、故障写入、重启/compaction、撤权与配额检查 |

三项都不再悬着等下一本书选择方案；但本包不把它们的**现场证据**改成 PASS。当前状态见 [STATUS](../STATUS.md)；有限实施顺序见 [IMPLEMENTATION](../plans/IMPLEMENTATION.md)。
