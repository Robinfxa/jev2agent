## 实施栈与复用

provider 工程逻辑以 Python 3.11+、标准库 SQLite 为首发交接选择，MCP transport 使用核验过的 SDK，不手写一套协议协商。**此选择不表示本包已经提供 provider。** 具体依赖版本在 W1a 的真实环境锁定，不能在无来源时声称某个 SDK 版本“最新稳定”。已有 lab 仅作测试和机制参考，不当生产授权/持久化实现直接搬入。

如果目标 Codex 版本存在可验证等价的原生 source/recall 能力，可提出**局部复用变更**并移除胶水；要求保持同一授权、原文、版本、回退和证据合同。这不是继续等未定方案：默认实现路径已经是本包的局部 provider＋事务存储。

## 范围预算

不新增通用事件总线、全库索引、独立评测平台、生成式摘要、OBSERVE、review/completion 或第二个“监督 Codex”。不因接缝难验而换成主模型行动后的重复审批，也不因已写大量文档而强行保留 C。
