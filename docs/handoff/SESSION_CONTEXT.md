# 会话背景

保留前序会话中的用户意图与取舍背景；现行状态以 [项目状态](../STATUS.md) 为准，工程语义以 [架构合同](../architecture/ARCHITECTURE.md) 为准。

## 用户已明确的方向

- 指定 Codex 为宿主，架构成书已收束；下一步是有限实施，不从 v0.6 无限扩写。
- 支持与反对要落到证据、代价和推翻条件；可查 GitHub、社区与官方资料，接口依据须追到版本化一手来源。
- 借用 ValueHermes 的总书、模块、证据与收束方法，不绑定其业务或技术栈。
- 目标是降低完整任务无效工作与真实成本；首发只做一种只读搜索结果的 ADMIT＋原文 recall。
- Jev 是可替换候选后端，不是必装组件，也不是必须证明有价值的前提。

## 保留的取舍理由

- 优先宿主原生能力、静态指令与确定性规则，避免在主模型已有判断后增加重复监督。
- 自有工具返回边界减少对全局 hook 的依赖；发送成功不等于模型请求已收到。
- Hard Context 来自真实任务与权限合同，不由隐藏答案或语义分数反推。
- 可召回不能撤销先前错误；首次压缩率不能代表质量、最终成本或收益。
- 比较 B/A、C/B、C/A；允许保留 B、删除 C 或停止项目。
- 事件级失败与块级弃权分开；停筛不删除仍合法的原文召回。

详细规则见架构和宿主合同。历史材料不构成新增授权或当前验证事实。
