L0001 | # §03 宿主适配与事件接入
L0002 | 
L0003 | > 状态：首发接缝 Draft。没有具体宿主支持结论。本章定义“必须证明什么”，不宣称已经证明。
L0004 | 
L0005 | ## 0. 定位、范围与非目标
L0006 | 
L0007 | 把宿主真实的捕获与交付能力映射成可核验合同；不创造 agent loop，不建立通用事件总线，不把收到通知当作拥有执行权。材料列举的 `TOOL_RESULT / CONTEXT_ADMISSION / SUBAGENT_RETURN` 是目标事件词汇，不是本轮已确认的 API。[D3：Agent Event Stream](../../../references/discussions/D3-runtime-stories.md)
L0008 | 
L0009 | ## 1. 首发边界
L0010 | 
L0011 | 仅考虑一种结构明确、只读且能完整捕获返回值的搜索工具。推荐最初使用受控工具包装；具体宿主、版本、调用接口仍待 R01 核验。
L0012 | 
L0013 | 包装层只改变获授权结果的披露，不改变搜索参数、不增加搜索范围、不调用更有权限的资源。不支持的类型回原流程。任意 shell 输出、实时流和多模态结果不伪装成已支持。
L0014 | 
L0015 | ## 2. 能力证明矩阵
L0016 | 
L0017 | | 能力 | 必须看到的证明 | 不能充当证明 |
L0018 | |---|---|---|
L0019 | | 首次读取前捕获 | 受控测试能证明模型请求中的工具内容来自包装后的结果 | 日志里有 PostTool 通知 |
L0020 | | 可替换返回体 | 替换内容进入真实下一次模型请求，tool call ID 与退出状态正确 | 单独函数测试输出正确 |
L0021 | | 完整性识别 | 识别 truncated / partial / timeout / permission error 等状态 | 只检查文本长度或 exit 0 |
L0022 | | 一次交付 | 重复事件、取消、后端迟到不产生双重工具响应 | 在单线程 happy path 成功 |
L0023 | | 召回可调用 | 实际 agent 能通过稳定入口取回原授权快照 | JSON 中写了 recallable=true |
L0024 | | 状态与身份绑定 | task/run/receiver/call/source version 能被核对 | 依赖 prompt 内自报身份 |
L0025 | | 关闭可还原 | 在约定返回边界与优化前基线相同 | 要求随机模型最终回答逐字一样 |
L0026 | 
L0027 | `MODEL_STEP_START` 等可选观察点缺失必须登记。缺少前置替换能力时，只能做观察或局部包装，不宣布 ADMIT 全局启用。
L0028 | 
L0029 | ## 3. 输入 / 输出最小接缝
L0030 | 
L0031 | 输入是已授权的工具返回、调用身份、返回完整性、当前状态版本及本次配置。输出是原基线返回或合法 Disclosure Envelope，并带宿主可消费的交付状态。
L0032 | 
L0033 | 适配器不得让工具文本决定自身权限、状态 ID 或策略版本。无法建立可信绑定时旁路。首版只处理完成的非流式响应；新调用不共享可变的全局“当前结果”。
L0034 | 
L0035 | ## 4. 并发与提交
L0036 | 
L0037 | 为每次工具返回绑定稳定 call ID、源快照和接收方；准备、策略选择、宿主提交三个动作可区分。这里要求的是幂等和可观察的提交结果，不承诺分布式“严格一次”。
L0038 | 
L0039 | 后端结果在事件取消或响应提交后到达，只能废弃并记录；不得再次注入。接收方目标或权限已变化时，旧决策不再消费。若宿主无法确认提交状态，标记 `delivery_unknown`，由宿主恢复机制处理，不能盲目追加第二份响应。
L0040 | 
L0041 | ## 5. 不可见范围
L0042 | 
L0043 | 覆盖指标有两类：占工具事件的比例与占基线执行成本的比例。未包装通道必须出现在报告中，不能只展示被筛选的样本。绕开包装的合法动作不等于 agent 违规，也不能为提高覆盖暗中禁掉它们。
L0044 | 
L0045 | ## 6. 失败、成本与验证
L0046 | 
L0047 | 语义后端失败通常回确定性基线；权限失败仍由权限系统拒绝；存储失败不创建虚假 recall handle。最小记录无法完成时禁用 deferral，详见 §14。
L0048 | 
L0049 | 测试必须覆盖关闭透传、非目标结果旁路、工具报错、源截断、并发乱序、取消、超时、迟到响应与真实下一轮请求内容。首个真实接入 smoke test 未通过前，所有宿主名称只出现在候选列表。
L0050 | 
L0051 | ## 7. 取舍与未决
L0052 | 
L0053 | 推荐包装边界是为了局部可证明，不代表长期最佳集成方式。若原生宿主已提供等价且可靠的接缝，应复用并删除自建包装。Q02 / R01 / R02 保留待核；字段映射和真实版本证据缺失，不能定稿。
L0054 | 
L0055 | ## 8. v0.2：接入证据必须落在真实模型请求边界
L0056 | 
L0057 | E0 的观察点不是包装函数自己的返回值，而是**宿主实际发送的下一次模型请求**。分别保留原始授权工具返回、包装结果、出站请求中的工具消息、调用 ID 与响应确认；确认 request 中没有绕过包装再次附带原全文。
L0058 | 
L0059 | 准备 source/decision 可以在局部完成，发送属于宿主的外部副作用。没有宿主证据时，只能声称本地准备成功。不要用一个模拟 `send()` 函数通过单测来宣布真实前置捕获成立。
L0060 | 
L0061 | 关闭透传需要比较约定返回边界的内容、状态码、警告、顺序及身份；不比较最终随机模型输出逐字相同。支持范围还应明确：非流式、无副作用的只读工具、单种返回表示。流式截断和任意 shell 扩展单独验证。
L0062 | 
L0063 | ## 9. v0.2：时序、上下文绑定与并发
L0064 | 
L0065 | 接收方、任务合同/显式目标、保护规则、授权版本、源 hash 和 policy/config 构成一个决定上下文。发送前核对这些相关依赖，变化则废弃旧选择；不能只比较墙钟时间。
L0066 | 
L0067 | 区分 `state_revision`（捕获时完整状态标识）与 `decision_context_revision`（影响该选择的已声明依赖）。无关 telemetry 计数增加不应自动使所有并发结果失效；但哪些字段可排除必须由合同说明，不能悄悄忽略新用户要求。首版无法可靠跟踪依赖时保守回基线。
L0068 | 
L0069 | 同一 recipient 的互相依赖结果可以由宿主串行提交；不能为提高筛选覆盖而自行重排主模型尚未接收的工具响应。不同调用共享只读源引用可以，共享一个可变的“当前任务结果”不可以。
L0070 | 
L0071 | E0 逐项执行清单见 [接入验证合同](../../experiments/E0-integration-contract.md)。本地 `lab/` 只覆盖有限事件序列，不能证明真实线程、网络和进程崩溃行为。
L0072 | 
L0073 | ## 10. v0.3：覆盖与分析总体的区分
L0074 | 
L0075 | 真实接缝可覆盖比例是部署约束，不是实验分母。运行 C 后工具请求、输出大小和调用次数可能改变，不能用“C 实际触发的事件”和“B 中大小相近的事件”替代任务级分配。E1 记录 A 的完整任务分布，E4 主分析保留未覆盖、旁路和取消单位，过程事件用于解释而非重建总体。
L0076 | 
L0077 | 适配器应能够把事件归到预分配 experiment/unit/call，而不是根据最终所走回退路径重新改 arm。实验单位定义归 §12.14，真实平台如何携带身份仍待 E0。
L0078 | 
L0079 | ## 11. v0.4：本地样机不填补真实接入证据
L0080 | 
L0081 | `lab/baseline` 实际执行本地文档查询、产生显示结果并落盘，但没有捕获任何外部模型请求、真实 agent recall 或宿主确认。因此 E0 依旧未通过。
L0082 | 
L0083 | 真实适配器需将此处逻辑责任映射到已有原生协议，尤其证明来源状态、身份授权和超限读取路径。不能让测试 CLI 的自报 run/recipient 充当认证，也不能把本地 READY 标记提升为真实发送状态。
