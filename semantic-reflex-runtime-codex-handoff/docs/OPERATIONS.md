# 运行、隔离与回退交接

这是需要实施者落地的操作合同，不是本包已经安装的运行器。首发语义层关闭，真实 admission 关闭；只可在批准的 smoke 中验证。

## 启动

操作方生成受保护 run manifest，声明单任务、工作区和授权文件、Hard/Soft、principal binding、epoch、source quota 和运行/保留限制。先验证该进程/挂载边界不能被 Codex 原生工具改写，再启动 provider 与 Codex 配置。manifest 缺必填项、目标版本不匹配或工具 schema 漂移，启动器拒绝启用干预。

provider 私有 SQLite 不放在仓库中，不把整个交接包的 oracle/fixtures 暴露给受测 Codex。一个 run 一个授权域，凭证和跨域状态不存工具参数中。运行器身份、MCP 通道和文件隔离并不是已经由本包实现的功能；现场必须给出配置和攻击性尝试记录。

## 运行和预算

只读搜索不接受 shell；所有新源检查容量再在事务中写入源/视图/最小记录。查询耗时、完整原结果、目录/恢复、模型调用和内部重试都入账。预算以该 Codex 版本的实际表示与限额校准；本地 UTF-8 字节阈值不能冒充 token 上限。

`full=true` 和 Hard 闭包先于选择。源不能保存时不得生成延后引用；全文装不下必须走已经验证的页式读取，连最小页都装不下就报告限制。不能把一个超限全量响应标成“回退成功”。

## 停止与恢复

| 触发 | 必须动作 |
|---|---|
| 关闭语义 | 停新语义调用；已验证 B 仍可用，其他均保持原模式 |
| 关闭 admission | 停新增 D；已经合法发布的 recall 仍服务 |
| 活跃配额耗尽 | 不逐出承诺源；拒绝新增保存/延后，计量影响 |
| provider 崩溃 | 重启同 run 存储并核对 manifest；未确认交付保留 unknown，不主动 replay |
| 任务/权限更改 | 更新 epoch，阻止旧决策提交，失权读拒绝；需要新任务则新 run |
| 回滚代码 | 不破坏活跃源读取；兼容不足则保留旧 reader 排空或拒绝升级 |
| Codex compaction | 同 run 恢复目录继续可调用；模型是否主动使用另作效果验证 |
| 人工明确关闭 run | 停服务、按授权保留/删除合同清理；已有模型上下文不可撤回 |

一次断连/模型最终回答都不能单独作为源已无消费者的充分条件。若部署有最大运行期限，期限和错误行为必须在启动/披露合同中公开，并验证不是静默逐出。

## 数据外发

provider 首发无远端语义后端。Codex 自己的模型数据发送属于其获准原流程，不等于额外授权 Jev。以后启 C 需批准 endpoint、数据类别、凭据提供方、存储/日志策略和价格计量；本包不预选 Jev 版本、不引用旧聊天价格。

## 异常分流

权限错误拒绝；事件级语义失败退基线；块级弃权保护；发送不明停受影响路径；不是统一 fail-open。审计细节对模型的可见性受同一授权控制，隐藏路径和存储位置不在报错中泄露。
