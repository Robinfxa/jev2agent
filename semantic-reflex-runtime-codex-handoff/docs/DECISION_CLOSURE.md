## 3. 外部研究不再无限展开

R01/R03 只核验已选 Codex 的本地前置输出、授权和恢复；R02 只为当前原生 A/强 B 做版本化比较；R04 在 W4 核验后端；R05 在 W2/W5 核实实际成本；R06 随 OBSERVE 后置。来源类型和验证状态仍按原研究纪律记录。

本轮没有外部研究结果。用户材料里提及 Codex/MCP 的旧示例只是历史线索，不能证明指定 2026 年二进制的能力、价格或安全行为。

## 4. 三处旧冲突已整合

PATCH-01：设计批准与对象级验证分开。PATCH-02：四能力是长期版图，不是首发。PATCH-03：事件不可用与合法块弃权分开，保护闭包超限不得回到会延后它的B。[原补丁](../references/closeout/PATCHES.md) 保留。

本轮另有五项具体工程裁定 CX01–CX05，目的是绑定已指定宿主，不是新建五个功能模块。若实际 Codex 事实推翻某项，只修该绑定；不自动从0.6继续加书。

## 5. 三类“关闭”的不同含义

**设计选择已关闭：** 不再问做哪个宿主、在哪筛、谁授权、源存哪里、如何召回。

**实施验收未关闭：** 必须用实际 Codex 证明所选路径成立。无法联网/无二进制不是通过理由，F1–F3 现场状态为 OPEN。

**产品效果未关闭：** 必须按 E1–E5 判断质量、净值和维护成本。结论可以删除 C 或停止本切片，不因此要求再丰满架构。
